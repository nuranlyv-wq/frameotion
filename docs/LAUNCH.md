# Public release checklist

Publish only the reviewed release export, never this working directory wholesale.
Imported client videos, music, sound packs, account data, references, model weights
and local configuration are excluded. MIT covers Frameotion-owned code only.
Dependencies retain their own licenses; Remotion has separate commercial terms.

## Distribution

Lead with a short real screen recording: prompt → editable scene → PNG preview →
MP4. Explain that the connected assistant directs and the local engine renders.
Show the setup command and hardware requirements before asking for a star.

Publish a tagged release with verified setup instructions and known limitations.
Submit to MCP directories using their actual requirements. Share personally in
relevant communities only where promotion is welcome. Do not buy stars or spam.
Measure successful installs, first renders, reported bugs and returning users.
